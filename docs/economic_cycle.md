# 전체 경기 사이클

투자 대시보드의 **전체 경기 사이클** 탭 (`dashboard.html#economic-cycle`)에서 한국·미국·중국의 경기 방향을 대략적으로 비교한다. 개별 산업 사이클 점수나 종목 매수 신호와 별도로 보는 참고 화면이다.

## 화면과 해석

- 경기 시계: 세로축은 지표 수준, 가로축은 정확히 3개월 전 대비 변화(포인트). 큰 점은 최신 관측치이며 작은 점과 선은 과거 경로다.
- 한국: 동행·선행지수 **순환변동치**를 사용한다. 원지수의 기준연도 100과 혼동하지 않는다.
- 미국·중국: OECD의 진폭조정 경기선행지수(CLI)를 사용한다.
- 한국 추이: 2025년 9월~2026년 8월의 12개월. 범례로 계열을 숨기거나 표시하고 슬라이더로 월별 값을 확인한다.
- 용어: 동행, 선행, CLI, 순환변동치, 100 기준, 3개월 변화, 포인트(p), 네 국면과 기준월을 접이식 설명에 포함한다.

| 지표 수준 | 3개월 변화 | 화면의 분류 |
|---|---|---|
| 100 아래 | 상승 | 회복 |
| 100 위 | 상승 | 확장 |
| 100 위 | 하락 | 둔화 |
| 100 아래 | 하락 | 위축 |
| 정확히 100 또는 변화 0 | 경계 | 경계 |

100은 장기 추세 기준이다. 100 아래라는 이유만으로 공식 경기침체를 뜻하지 않는다. 분류는 화면의 단순 규칙이며 공식 경기국면 판정이나 주가 예측이 아니다. 서로 다른 지표의 높이를 경제성장률이나 국가 순위처럼 비교하지 않는다.

## 자료와 기준시점

**2026-10-10에 확인한 공개자료 스냅샷이며 자동 수집·갱신하지 않는다.** 대시보드를 재생성해도 이 자료의 기준월은 그대로다.

| 계열 | 수록 기간 | 최신 기준월 | 원출처 |
|---|---|---|---|
| 한국 동행·선행 순환변동치 | 2025-08~2026-08 | 2026-08 | 국가데이터처 산업활동동향 / e-나라지표 |
| 미국·중국 OECD CLI | 2025-05~2026-09 | 2026-09 | OECD SDMX API |

- [한국 경기종합지수 원표](https://www.index.go.kr/unity/potal/eNara/sub/showStblGams3.do?freq=M&idx_cd=1057&period=N&stts_cd=105701)
- [OECD CLI 설명](https://www.oecd.org/en/data/datasets/oecd-composite-leading-indicators-clis.html)
- [이번 조회에 사용한 OECD CSV](https://sdmx.oecd.org/public/rest/v1/data/OECD.SDD.STES,DSD_STES@DF_CLI,4.1/USA+CHN.M.LI...AA...H?startPeriod=2025-05&endPeriod=2026-09&format=csvfile)

한국은 3개월 변화 산출이 가능한 2025-11~2026-08의 10개 점을 표시한다. 미국·중국은 최근 12개 점을 표시한다. 국가별 마지막 기준월이 다름을 화면에 명시한다. 과거 값도 이후 수정될 수 있으며 당시 발표본을 보존한 백테스트 데이터는 아니다.

## 구현과 업데이트

- `docs/economic_cycle_panel.html`: 화면, 용어, 원자료 배열, 출처 링크와 로컬 표시 설정. Codex 전용 API 없이 동작한다.
- `docs/dashboard_template.html`: 탭과 패널 삽입 위치.
- `scripts/build_dashboard.py`: 대시보드 생성 시 패널을 삽입한다. 기존 Pages 재생성 경로에서도 유지된다.
- 차트 라이브러리는 버전을 고정한 D3 7.9.0 CDN을 사용한다.

업데이트 시 원출처에서 연속 월별 값을 확인한 뒤 패널의 `km`, `om`, 각 계열의 값 배열, 확인일·기준월·경로 개수 라벨과 이 문서를 함께 바꾼다. 3개월 변화는 연속 월 배열의 세 칸 전 값을 사용하므로 누락 월을 제거하고 이어 붙이지 않는다. 결측이 있다면 먼저 날짜 기반 비교 및 결측 표시로 계산을 변경해야 한다. FRED와 OECD의 수정 시점이 다를 수 있으므로 같은 계열에 서로 다른 조회본을 섞지 않는다.

일반 배포 재생성은 기존 `python scripts/render_dashboard_for_pages.py`를 사용한다. 이 명령은 다른 대시보드 데이터도 기존 규칙에 따라 갱신한다. 화면에서 확인할 사항은 탭 전환, 직접 해시 접근, 숨겨진 탭에서의 초기화, 범례 표시 전환, 월 슬라이더, 모바일 폭이다.

## 주가 계산과의 관계

대화에서 정리한 `주가 = EPS × PER`와 필요 EPS 역산은 개별 기업의 가격 부담을 검토하는 별도 도구다. 전체 경기 시계만으로 미래 EPS·PER나 호황 지속 기간을 계산하지 않는다. 이번 탭에는 실제 경기 지표와 해석만 반영했다.
