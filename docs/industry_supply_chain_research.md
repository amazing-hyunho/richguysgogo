# 산업별 소부장 조사 지도

조사 확인일: 2026-09-09

상태: 25개 산업의 초기 지도. 전수조사·투자 적합성 평가·사이클 시차 검증은 완료되지 않았습니다.

- 조사 순서는 학습·자료 수집 순서이며 매수 우선순위가 아니다.
- 제품·적용 산업은 확인 사실, 사이클 전달 경로는 미검증 가설이다.
- 공개되지 않거나 확인하지 못한 매출 비중·시차는 null이며 0으로 처리하지 않는다.
- 산업별 핵심 사례로 만든 초기 지도이며 전체 상장사 목록·심층조사 완료를 뜻하지 않는다.
- 동일 기업이 여러 산업에 나타나도 매출·수혜를 중복 합산하지 않는다.
- 은행·증권·소프트웨어는 서비스 공급망이다. 해운·항공은 직접 납품과 간접 연결을 구분한다.
- 제조기업 자신의 산업 지도에서는 공급망의 기준 기업을 포함한다. 모든 행이 하위 협력사는 아니다.
