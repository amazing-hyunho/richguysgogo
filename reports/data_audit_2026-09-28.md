# 2026-09-28 데이터 누락 점검

## 범위와 결과

- SQLite 업무 테이블 45개 전체의 건수·저장 기간을 조사했다. `PRAGMA quick_check` 결과는 `ok`다.
- 시장·매크로·수급·국내 기준금리의 숫자 항목 58개 중 최근 7일 이내 저장값이 있는 항목 49개, 오래된 항목 8개, 저장 이력이 없는 항목 1개다. 저장일은 원천 통계의 발표일을 보장하지 않는다.
- 화면에는 중복된 과거 호환 필드를 제외한 시장·매크로·수급 52개 항목의 점검표를 추가했다. 기존 한국 기준금리 카드는 유지된다.
- 최신 대시보드의 DB 연결, 생성 HTML, 내장 JavaScript 구문, 점검표 표시 함수를 검증했다. 브라우저의 로컬 파일 URL 보안 정책 때문에 실제 시각적 렌더링은 검증하지 못했다. 공개 사이트 반영 여부는 별도 검증하지 않았다.

## 확인된 원인과 처리

| 항목 | 확인된 원인 | 처리 / 남은 문제 |
|---|---|---|
| 한국 수출 YoY | ECOS `901Y011` 조회가 INFO-200을 반환한다. 공식 통계 목록에는 통관 수출입 총괄이 `901Y118`, 수출금액이 `T002`로 제공된다. | 수집 코드 수정. 현재 제공되는 2026-07과 2025-07 수출금액을 비교해 오늘 행의 결측을 복원했다. 9월 수출 실적이라는 의미는 아니다. |
| 일별 매크로 | 백필 SQL이 재수집 결측으로 기존 값을 덮어쓴다. 대체 심볼 하나의 오류도 전체 수집을 중단시킬 수 있다. | 기존값 보존, 심볼별 실패 격리. 같은 날짜의 저장 스냅샷을 근거로 32개 셀을 복원했다. WTI의 대체값으로 브렌트를 사용하던 처리도 제거했다. |
| 심화 매크로 | 단독 백필 실행 시 `.env`를 읽지 않으며, 일부 지표가 결측이면 정상 지표까지 NULL로 덮어쓸 수 있다. | 환경 로드와 정상값 보존 처리 추가. |
| 외국인·기관·개인 수급 | 최신 실행 기록에서 Naver HTTP 410, KRX HTTP 400. 최근 유효 순매수는 9월 17일. | 백필과 일일 저장의 NULL 덮어쓰기 방지. 다른 날짜의 첫 행을 요청 날짜로 바꾸던 Naver 파싱 제거. 빈 값은 0으로 바꾸지 않는다. 현재 원천 수집은 미복구. |
| 외국인 누적 수급 | 20일 누적은 9월 17일, 60일 누적은 3월 17일 이후 유효값이 없다. 누적 창의 결측은 계산 불가로 이어진다. | 과거값을 최신값으로 표시하지 않고 점검표에 지연 표시. 원천 수급 이력 복원이 더 필요하다. |
| PMI | 기존 정규식의 이중 이스케이프 오류. 기존 공개 주소는 현재도 2025-12 보고서를 반환한다. 최신 월 보고서 직접 요청은 로그인 화면으로 이동한다. | HTML·공백 파싱 수정 및 보고서 월 검증. 오래된 값을 현재 값으로 저장하지 않는다. 자동 수집 복구는 미완료. |
| 실질금리 등 화면 가시성 | 실질금리는 DB에 있지만 대시보드 SELECT에서 제외돼 있다. 주요 카드에 나오지 않는 지표도 있다. | 실질금리 payload 추가, 전체 점검표에 지표별 값·마지막 저장일·최근 30행 결측 수 표시. |
| 동기화 완료 처리 | 단계가 실패해도 `sync_all`이 정상 종료·자동 커밋할 수 있다. | 환경 변수 로드, 자식 프로세스 실패 시 비정상 종료하고 자동 커밋 단계에 진입하지 않도록 수정. 자식 스크립트가 자체 오류를 숨기는 경우까지 검출하는 것은 아니다. |

## 나머지 데이터 범위

- 종목 마스터 4,532개. 9월 27일 주간 컨센서스 3,941개, 9월 28일 일일 컨센서스 22개. 일일 워치리스트와 주간 전체 수집의 범위가 다르므로 22개 자체를 전체 누락으로 판단하지 않았다.
- 재무지표 2,875행: KRW 2,782행 / 2,781종목, USD 93행 / 10종목. 전 종목의 모든 재무 기간을 보유한다는 의미는 아니다.
- 산업 사이클 v1/v2는 9월 27일에 각각 25개 신호가 있다. 최신 가격 요인 72행의 completeness는 1.0, v2 25행도 1.0이다. v1은 22행이 0.75, 3행이 0.55여서 일부 입력 부족이 남아 있다. 각 모델의 completeness 정의가 다르므로 직접 비교하지 않는다.
- `daily_price_kr`, `stock_daily`는 0행이다. `stock_daily` 저장 함수는 구현상 stub이다. `thesis_signal_daily` 마지막 날짜는 8월 9일이다. 미구현/선택 기능과 장기 미갱신을 구분해야 하며 이번 변경으로 자동 수집 범위를 확장하지 않았다.
- 월별·분기별 매크로의 `data_date`/`published_at` 등이 비어 있어 원천 발표 시점의 완전한 검증은 불가능하다.
- 최근 실행 파일에는 9월 23~26일이 없다. 실행 이력 공백과 거래일 가격 결측은 같은 의미가 아니다.
- README와 .gitignore에 기존 merge conflict 표식이 남아 있다. 이번 데이터 수정 범위에서는 변경하지 않았다.
